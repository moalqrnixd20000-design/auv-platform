# Submission checklist

Notes for the team. The competition platform asks for four items; the site has a
place for each.

| Item | Where on the site | Notes |
|---|---|---|
| Project photo | Project Materials, second card | A high-quality representative image of the AUV project. Use the team's own design or real photographs; do not create fake hardware photography. |
| Poster or brochure | Project Materials, first card | A0 scientific poster, in English. |
| Demonstration video | Video section | Arabic or English; shows the interactive prototype clearly and quickly. |
| Google Drive link | Project Materials, third card | Sharing setting: "Anyone with the link can view". |

## A0 poster requirements

- English; specific, technically meaningful title; no ambiguous abbreviations in the title.
- Introduction as an inverted triangle: general context, current knowledge / existing solutions, problem / gap, objective.
- Methodology shown with flowcharts; minimal unnecessary text.
- Clear numerical results and graphs, using only real or clearly labelled simulated values.
- High-resolution screenshots; figures labelled Figure 1, Figure 2, and so on.
- A dedicated originality / innovation zone with a direct comparison to existing alternatives.
- Conclusion with measurable impact where supported; a specific future-development direction.
- References compressed into a QR code; the official template; about 20% whitespace.

Screenshots of the site's interactive demo and the "How It Works" flow can be reused as poster figures.
