# Tuwaiq submission checklist

The competition platform requires four items. The site has a slot for each (section "Project materials").

| # | Item | Site slot | Status | Notes |
|---|---|---|---|---|
| A | Project photo | `.material--photo` | To be uploaded | A high-quality representative image. Use the team's official design where appropriate; **do not create fake hardware photography.** |
| B | Poster or brochure | `.material--poster` | Coming soon | A0 scientific poster, English. |
| C | Demonstration video | `.material--video` | Coming soon | Arabic or English; should show the interactive prototype clearly and quickly. No claims of real-world operation. |
| D | Google Drive link | `.material--drive` | Link not yet added | Sharing setting must be **Anyone with the link can view**. Never invent a URL. |

## A0 poster requirements (for the team — from the brief)

- English language; specific, technically meaningful title; no ambiguous abbreviations in the title.
- Introduction as an inverted triangle: general context → current knowledge / existing solutions → problem / gap → objective.
- Methodology shown visually with flowcharts; minimal unnecessary text.
- Clear numerical results and graphs — **only real, measured or clearly labelled simulated values**.
- High-resolution screenshots; figures labelled Figure 1, Figure 2, …
- A dedicated Originality / Innovation zone with a direct comparison to existing alternatives.
- Conclusion with measurable impact where supported; a specific future-development direction.
- References compressed into a QR code; the official template; about 20% whitespace.

The site's own figures (Figure 1–6) are numbered in reading order and can be reused as poster figures
once the reference images' credits are cleared.
